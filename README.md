# 시니어영어방문학습 홈페이지 1차 웹 시안

`index.html`을 웹브라우저에서 열면 바로 확인할 수 있습니다.

## 반영 완료
- 브랜드명: 시니어영어방문학습 (유지)
- 방문 가능 지역: 일산서구
- 상담 신청 접수 방식: 전화 / 문자 / 상담 신청 폼 (3채널)
- 대표자 소개 문구: 원본 그대로 유지
- 학습지·단어카드 이미지: 실제 사진 준비 전까지 사이트 톤에 맞춘 커스텀 SVG 일러스트로 대체 (`.service-card .image-placeholder` 내부 `<svg>`)

## 실제 오픈 전 교체할 부분
- 전화번호 (현재 미공개 — 확정되면 CTA 버튼에 tel:/sms: 링크 연결 필요)
- 방문 학습지 실제 사진 (`article.service-card:nth-of-type(1)` 내 svg 교체)
- 영어단어카드 실제 사진 (`article.service-card:nth-of-type(2)` 내 svg 교체)
- 대표자 사진(원할 경우)
- 상담 신청 폼 실제 접수 연동 (현재 `submitInquiry()`는 화면 확인용 더미 동작 — 문자/이메일/구글폼/카카오톡채널 등과 연결 필요)
- 사업자 정보 및 개인정보처리방침/이용약관 등 운영에 필요한 고지

## 기획안 반영
홈 → 브랜드 소개 → 서비스 소개 → 추천/예외 안내 → 통계 → 이용 방법 → FAQ → 상담 CTA 순서로 구성했습니다.
