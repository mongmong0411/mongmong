# 시니어영어방문학습 홈페이지

"단어에서 문장으로, 시니어 맞춤 방문 영어 학습"을 헤드카피로 하는
**시니어 대상 방문형 영어 학습 서비스**의 공식 소개 웹사이트입니다.

`index.html`을 웹브라우저에서 열면 바로 확인할 수 있습니다.

## 구성
| 경로 | 설명 |
|---|---|
| `index.html` | 단일 페이지(One-page) 구성. 앵커(`#brand`,`#service`,`#recommend`,`#why`,`#howto`,`#faq`,`#consult`)로 각 섹션 이동 |
| `css/style.css` | 전체 스타일 (시니어 친화적 큰 글씨·고대비·반응형) |
| `js/main.js` | 모바일 메뉴 토글, FAQ 아코디언, 상담 폼 열기/제출, 헤더 스크롤 효과 |

## 페이지 섹션
홈(히어로) → 브랜드 소개 → 서비스 소개 → 추천 대상 안내 → 데이터로 보는 필요성(통계) → 이용 방법 → FAQ → 상담 신청(CTA + 폼)

## ⚠️ 실제 오픈 전 반드시 확인/교체할 부분
- **전화번호**: 현재 임시 번호(`1588-9999`)가 `tel:` 링크와 표시 텍스트에 들어 있습니다. 실제 상담 전화번호로 교체가 필요합니다.
- **히어로/브랜드/서비스 이미지**: 현재 `index.html`의 `<img src>`가 외부 임시 프록시 URL(`sspark.genspark.ai/cfimages?...`)을 참조하고 있습니다. 이 URL은 만료되거나 접근이 끊길 수 있으므로, 실제 배포 전에 이미지를 저장소 내부(예: `assets/images/`)로 옮기고 경로를 로컬 파일로 교체해야 합니다.
- **상담 신청 폼 연동**: `js/main.js`의 `fetch('tables/consultations', ...)`는 원본 제작 도구(Table API)에 종속된 엔드포인트로, 이 정적 사이트 단독으로는 동작하지 않습니다. 실제 운영 시 이메일 발송, 구글폼, 카카오톡 채널, 자체 백엔드 API 등으로 연동을 교체해야 합니다.
- **대표자 사진**(원할 경우), **사업자 정보 및 개인정보처리방침/이용약관** 등 운영에 필요한 고지 추가 필요.

## 기술 스택
- HTML5 / CSS3 (반응형, Flexbox & Grid)
- Vanilla JavaScript (프레임워크 없음)
- Font Awesome 6 – 아이콘
- Google Fonts – Noto Sans KR – 한글 폰트
