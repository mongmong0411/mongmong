# 시니어영어방문학습 홈페이지

"단어에서 문장으로, 시니어 맞춤 방문 영어 학습"을 헤드카피로 하는
**시니어 대상 방문형 영어 학습 서비스**의 공식 소개 웹사이트입니다.

`index.html`을 웹브라우저에서 열면 바로 확인할 수 있습니다.

## 구성
| 경로 | 설명 |
|---|---|
| `index.html` | 단일 페이지(One-page) 구성. 앵커(`#brand`,`#service`,`#recommend`,`#why`,`#howto`,`#faq`,`#consult`)로 각 섹션 이동 |
| `css/style.css` | 전체 스타일 (시니어 친화적 큰 글씨·고대비·반응형) |
| `js/main.js` | 모바일 메뉴 토글, 스크롤 연동 내비게이션 강조, FAQ 아코디언, 상담 폼 열기/제출, 헤더 스크롤 효과 |
| `assets/illustrations/` | 히어로·브랜드·서비스 카드에 쓰이는 커스텀 SVG 일러스트 (실사 사진 준비 전 임시) |

## 페이지 섹션
홈(히어로) → 브랜드 소개 → 서비스 소개 → 추천 대상 안내 → 데이터로 보는 필요성(통계) → 이용 방법 → FAQ → 상담 신청(CTA + 폼)

## 업그레이드 반영 내역
- 외부 임시 이미지 프록시 URL을 저장소 내부 커스텀 SVG 일러스트(`assets/illustrations/`)로 교체하여 외부 의존성 제거
- 상담 신청 폼의 원본 제작 도구 전용 API(`fetch('tables/consultations')`) 호출을 제거하고, 실제 접수 연동 전까지는 UI 흐름(제출 → 완료 화면)만 동작하도록 정리
- 시니어 친화적 접근성: 키보드 포커스 표시(`:focus-visible`), 모션 최소화 사용자를 위한 `prefers-reduced-motion` 대응 추가
- 스크롤 시 현재 보고 있는 섹션에 맞춰 상단 내비게이션 메뉴가 강조 표시되도록 개선
- 고정 헤더에 섹션 상단이 가려지지 않도록 앵커 이동 오프셋(`scroll-margin-top`) 추가
- 검색/공유 시 노출되는 Open Graph 메타 태그, `theme-color` 추가

## 배포 (GitHub Pages)
`.github/workflows/deploy-pages.yml` 워크플로우가 `claude/website-upgrade-loswuh` 브랜치에 푸시될 때마다
`index.html`, `css/`, `js/`, `assets/`를 GitHub Pages로 자동 배포합니다. 저장소 설정에서 별도로
Pages를 활성화하지 않았다면 워크플로우가 처음 실행될 때 자동으로 활성화됩니다.
배포된 주소는 저장소의 **Settings → Pages**에서, 진행 상황은 **Actions** 탭에서 확인할 수 있습니다.

> ⚠️ 이 저장소에는 이 브랜치 외에도 같은 주제로 작업 중인 `claude/website-upgrade-*` 브랜치가 더 있으며,
> 그중 일부(`claude/website-upgrade-men3wx`)에도 별도의 Pages 배포 워크플로우가 있습니다. GitHub Pages는
> 저장소당 하나의 라이브 주소만 가지므로, 여러 브랜치의 워크플로우가 각자 배포를 시도하면 **가장 최근에
> 실행된 워크플로우의 결과가 라이브 사이트를 덮어씁니다.** 최종적으로 어떤 버전을 배포할지 정리가 필요합니다.

## ⚠️ 실제 오픈 전 반드시 확인/교체할 부분
- **전화번호**: 현재 임시 번호(`1588-9999`)가 `tel:` 링크와 표시 텍스트에 들어 있습니다. 실제 상담 전화번호로 교체가 필요합니다.
- **실사 이미지**: 히어로/브랜드/서비스 카드는 현재 커스텀 SVG 일러스트로 대체되어 있습니다(`assets/illustrations/`). 실제 촬영 사진이 준비되면 해당 섹션의 `<img src>`를 사진 파일 경로로 교체해 주세요.
- **상담 신청 폼 연동**: `js/main.js`의 제출 핸들러는 현재 화면 확인용으로 완료 화면만 보여주며, 실제로 데이터를 저장/전송하지 않습니다. 실제 운영 시 이메일 발송, 구글폼, 카카오톡 채널, 자체 백엔드 API, Formspree 등 정적 사이트에서 쓸 수 있는 폼 연동 서비스로 교체해야 합니다.
- **대표자 사진**(원할 경우), **사업자 정보 및 개인정보처리방침/이용약관** 등 운영에 필요한 고지 추가 필요.
